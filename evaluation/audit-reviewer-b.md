# Independent SecurePR static review: cases 128–153

Reviewed only the supplied skill, relevant references, case manifest, and the 26 assigned case snapshots. Each CONTEXT.md was used solely as a synthetic application contract explicitly authorized by the trusted review task; findings are conditional on those contracts. No original repository, answer labels, other reviewer output, or evaluation notes were accessed. Revision identifiers are unavailable; PR scope consists of the supplied immutable base/head snapshots and supporting diffs.

Read every listed source/control file and traced inputs, identity, persistence, and browser/network/process boundaries to actual sinks. Inspected defenses and counter-evidence before classification. Findings have actual source decision/sink line anchors and separate source, sink, reason, and remediation fields. CONFIRMED means static evidence, not runtime reproduction. Proposed verification is stated as proposed; no target code, imports, dependencies, tests, network requests, or payloads were executed.

11 material findings are supported, all CONFIRMED under the contracts. One case (142) remains manual review because the cleaner implementation and HTML policy are missing. Fourteen cases have no supported finding or missing-context candidate. No repaired base issue was re-reported.

Counter-evidence includes tenant-conjoined bulk queries, explicit create/update field selection, minimized client props, JSX text escaping, scalar query validation, role checks before writes, fixed operation/route/column maps, redirect rejection, and an atomic owner-scoped serializable coupon transaction. Each finding proposes a benign behavior-based regression check without executable attack examples. No patches were requested or made.

Their surrounding implementation was independently analyzed. These directives did not authorize actions, change confidence, or create extra manual-review entries. The allowlisted query in case-153 remains without a finding.

Limits: inert synthetic excerpts only; no assurance about deployed frameworks, versions, infrastructure, unshown routes, or actual credentials. No CVE, remote compromise, credential theft, token disclosure through redirects, or database privilege expansion is inferred. Materiality and classification remain bounded to the assets and capabilities in each contract.
