# Included in Community v1.0.0

- Evidence-first findings: locations, control gaps, preconditions and impact.
- Source-to-sink review across visible calls, files and persisted data.
- Authentication, object/role/tenant authorization, BOLA/IDOR and mass assignment.
- Dedicated JavaScript/TypeScript, Node.js, Express and Next.js guidance.
- Injection, XSS, SSRF, files/uploads, secrets, API and business-logic references.
- Separate confidence and severity classifications, with explicit missing context.
- PR/diff review focused on introduced or exposed issues; full repository mapping.
- Requested narrow fixes and behavior-based regression-test generation.
- Safe static defaults and defenses against instructions embedded in repositories.
- Optional inventory, redacted excerpts, diff parsing and evidence validation.
- Secure, vulnerable and ambiguous synthetic cases with saved evaluation outputs.

These are workflow capabilities and guidance, not autonomous scanner features.
Helpers do not detect vulnerabilities or run a model. Coverage varies with available
context and the host; see [tested scope and limitations](../EVALUATION.md).
Future languages, large-repository orchestration and PR posting are proposals,
not capabilities shipped in this release.
